## 正文（中文，可直接复制）

> 小红书正文建议每 1–2 行换行，不要一大段。以下保留空行。

```text
背 B2/C1 单词时我发现一个问题：单词书按字母排，长难词之间看起来毫无关系，但它们经常是同一个拉丁词根变出来的。

比如 rad（拉丁语 radix，根）：
raíz (A2)
radical / radicar / arraigar / arraigo (B2)
erradicar / erradicación / radicalismo (C1)

这 8 个词在图上是同一组关系，不是 8 个孤立条目。

再比如 loqu（拉丁语 loqui，说）：
elocuente / elocuencia (B2)
coloquio / locución (C1)
locuaz / soliloquio / ventrílocuo (C2)

这组词阅读里很常见，但长得不像，按字母背很难串起来。

我把自己整理的词根关系做成了一个开源仓库：
232 个拉丁/希腊词根
1,423 个单词
1,513 条带类型的关系（派生 / 联想 / 易混）
1,419 个词带 A1–C2 标记

它不是背单词 App，也不提供释义。
仓库只存结构：词根、词形、关系类型、CEFR 级别、拉丁本源。
选一个词，复制预置指令到任意大模型（默认豆包，也可以换 ChatGPT / Claude / Gemini），让它现场解释词义、语体、搭配和近义词辨析。

为什么不直接存释义？
1. 词典释义和例句通常是受版权保护的汇编；
2. 静态副本容易过期；
3. 我更想要一张能改、能 diff、能提 PR 的“地图”，而不是一份复制来的内容。

边界说清楚：
· 不是 DELE 官方词表，CEFR 只是教学参考
· 不能拆拉丁词根的高频词（原生词、阿拉伯/日耳曼借词、功能词、不规则动词）另有一个 364 词清单
· 网页版首次加载要从 CDN 取 Mermaid，仓库视图可以离线看结构

适合谁：
已经在读 B1/B2 以上材料、经常遇到“好像见过但串不起来”的长词的人。
A1/A2 阶段可能用不上这么多词根，先把基础词和动词变位打好更实际。

GitHub 搜 es-raiz-vocab 就能找到。
开源、免费、无课程、无付费。
```

## 该平台的具体合规提醒

- **绝对化用语**：不写“最有效”“第一”“保证过 DELE”“必过”“百分百”“秒懂”“彻底解决”。可写“更适合”“对我来说”“可以试试”。
- **不伪造学习成果**：不写“用了两周 B2 上岸”“学员反馈”“提分 XX”。本项目没有这类数据。
- **不诱导互动**：不写“求收藏”“点赞过百更新”“关注我”。可以让内容本身值得收藏，但不要交换条件。
- **AI 内容标注**：笔记正文说明“释义由用户自己选择的大模型生成”，不要暗示仓库内置了权威 AI 释义。
- **版权**：不截词典 App 的释义页，不贴教材例句，不使用未授权字体/素材；本项目本身也不存释义和例句。
- **不蹭品牌**：不使用“不背单词”作为话题词或标题核心词。
- **不导流**：不出现微信、QQ、群号、二维码、其他平台账号。
- **不刷数据**：不买赞藏评，不多账号互推；短期数据异常会影响账号权重。
